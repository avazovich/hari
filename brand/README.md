# Hari brand assets

Brand name: **hari** · Korean: **하리**

This folder contains all eight Hari logo concepts. The original generated PNGs are preserved separately. SVG and EPS artwork uses real outlined vector paths, with exact brand color fills and no embedded raster images or font dependencies. PNG and WebP exports are rendered from these vectors.

## Folders

- **concepts-original/** — the eight original concept PNGs, in the requested aspect ratios.
- **vector/svg/** — all eight concepts as SVG, plus transparent variants; scalable and editable in vector design tools.
- **vector/eps/** — all eight concepts as EPS Level 3 for print/design applications.
- **png/background/** — clean vector-rendered PNGs with their intended backgrounds.
- **png/transparent/** — PNGs without the surrounding background; white wordmarks are intended for dark/pink surfaces. Icon tiles and circles remain part of the artwork.
- **webp/** — lossless transparent WebP versions.
- **icons/favicon/** — dew-drop favicon in SVG, a multiresolution ICO, and PNG sizes 16, 32, 48, 64, 128, and 256.
- **icons/app/** — gradient h app icon in SVG and PNG sizes 180, 192, 512, and 1024, plus apple-touch-icon.png. The tile fills the app export; these are brand icons, not an App Store upload bundle.
- **icons/site.webmanifest** — web app icon references relative to this file.
- **guidelines/** — color tokens, ordered asset manifest, and original generation prompts.
